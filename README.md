This application was done using Python. The program can be run by executing view.py, which launches the ui allowing uploads for three input files: input.txt, price.txt, and promotions.txt, after parsing the data, pressing the Run Optimization button runs the optimization algorithm and displays the result in the interface and also saves a version to output.txt.

To start the application run:

-python view.py (you should be inside {YOUR FILE PATH}\CS430-PROJECT)
-upload input.txt, price.txt, and promotions.txt the data in the files can be validated by clicking 'Parse Files'
-Run the optimization algorithm after by clicking 'Run Optimization' this will display the output on the ui and also save it to the output.txt file located in {YOUR FILE PATH}\CS430-PROJECT


Running Environment & Instructions
Environment
- Language: Python 3

How to Run the Application
1. Open a terminal.
2. Navigate to the project directory:
   cd {YOUR FILE PATH}\CS430-PROJECT
3. Run the program:
   python view.py

This will launch a graphical interface (UI) for uploading files and running the optimization.

Input Files Required
You must upload three input files:
- input.txt: List of items and quantities to purchase.
- price.txt: Unit prices for each item.
- promotions.txt: Promotional bundles available.

Usage Instructions
1. Launch the UI by running python view.py.
2. Upload the three required files.
3. Click “Parse Files” to validate the data.
4. Click “Run Optimization” to:
   - Execute the optimization algorithm.
   - View the output directly in the user interface
   - Save it in output.txt in the same folder.
